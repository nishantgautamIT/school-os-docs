Inventory and library integration

Share vendors, purchase approvals, receipts, locations and audit records. Track consumable quantities, individual equipment units, and library editions/copies with their own rules. A loan changes custody and availability; it does not automatically reduce school ownership or accounting value. Match supplier invoices and payments to accepted receipts.

Event packages for parents

Approved event photos → bounded ZIP worker → private S3 package → parent-specific application link in a message → verified guardian/audience/expiry check → short-lived download access. Support configurable expiry and revocation; downloaded files cannot be recalled. Reuse a package for an identical approved audience and meter download volume.

Features to validate

Build parent action lists, accessible delivery and event packages first. Test absence catch-up packs tied to actual classwork and lesson planning that checks available books/equipment before creating approved procurement requests. Reading and portfolio features already exist in competitors; differentiate through the complete workflow and measured usefulness.

Budget before revenue

Lightsail Linux 2 GB is $12/month; 4 GB is $24/month. At the planning assumption of ₹90/USD, those are ₹1,080 and ₹2,160 before taxes/FX and extras. Budget roughly ₹2,000–₹4,000 for a controlled Node pilot, before substantial gallery downloads and messaging. S3 costs include requests and outbound delivery as well as stored bytes. No capacity has been measured.

Launch sequence

Discovery and accountant review → foundation/imports → inventory/library → procurement and balanced financial posting → gallery packages and parent actions → controlled month-end and performance verification → AI enhancements. A provisional 16–24-week staged plan replaces the original core-only 10–12-week estimate; it is not a delivery guarantee.
